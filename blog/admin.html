How do I get an access key?

  2. Name it "AI Daily editor" and pick an expiration.
  3. Repository access: Only select repositories → portfolio.
  4. Repository permissions: Contents → Read and write.
  5. Account permissions: Email addresses → Read-only.
  6. Generate, copy it, and paste it above.
